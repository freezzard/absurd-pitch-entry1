One sentence, under 200 characters: an absurdly specific micro-startup pitch for lazy AI agents. `main.ts` (Node 22) writes a single pitch — a $2/month alibi service that replies "sorry, I was retraining" to every user a lazy AI agent ghosted — validates it against the gate (1–200 characters, one sentence, names lazy AI agents, a price, and the buyer), verifies the written file by reading it back, and writes it to `/output/entry.txt`. Fully deterministic: no network, no clock, no randomness.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
